## What's Different About This Project

mcp-timeline processes location history data, which the operator treats as
sensitive by default: the local version never transmits it anywhere, and a
future hosted version requires its own security and privacy review (see
`TERMS_AND_CONDITIONS.md`) before accepting real users. This project is a
personal-productivity and data-literacy tool, not a financial, medical, or
legal product, and does not offer advice in any of those domains.

## Allowed

- Publishing this project's source code and documentation publicly.
- Selling a knowledge product (a guide) teaching the underlying pattern.
- Offering a paid hosted version of the software, once it meets this
  project's own security and legal review gates.

## Restricted (requires pre-clearance)

- Monetizing this project in any form, until Outside Business Activity
  clearance for it has been obtained.
- Accepting real (even unpaid beta) users on a hosted version, until a
  security review and a reviewed Terms and Conditions are in place.

## Prohibited

- Naming any employer, colleague, or employer-internal system anywhere in
  this repository's code, commits, docs, or public output.
- Using any employer-internal information, tooling, or data in this
  project's design or implementation.
